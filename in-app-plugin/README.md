# ChatGPT / Codex 启动动画控制页

开场图标旋转**使用并修改了 [yshuang722-spec/codex-startup-animation](https://github.com/yshuang722-spec/codex-startup-animation) 的源码**（Artemis / Tom，MIT）；原文许可证位于 `licenses/artemis-startup-MIT.txt`。

本插件提供字体、颜色、位置、旋转速度、文字汇聚速度、启用开关，以及可选皮肤遮罩的滑块控制。完整动画播放在 Codex 原生窗口内，不另开全屏动画窗口。

请先安装 [codex-launch-animation 的 Windows 发布包](https://github.com/lh2-art/codex-launch-animation/releases/latest)，再打开控制页。MCP 服务使用 `%LOCALAPPDATA%\CodexLaunchAnimation` 中的本地运行时，不含作者的电脑路径。

配置写入当前用户的 `%APPDATA%\codex-launcher`；皮肤遮罩写入当前皮肤管理器的偏好设置。关闭动画不会删除外观设置。插件为非官方社区工具，Windows / Codex 版本兼容范围、安装、卸载及素材说明见仓库根目录 README。
